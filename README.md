# ПРОМОКОДЫЧ

Сайт с промокодами и бонусами на цифровые сервисы (Playerok, Kupikod, Lis-Skins и др.)
с полноценной админ-панелью. Простой, но красивый дизайн в стиле promik.net / promokodus.com.

## Возможности

**Публичная часть:**
- Закреплённая при прокрутке шапка с названием **ПРОМОКОДЫЧ** и логотипом (иконка `%`)
- Главная страница: большой баннер по центру + два маленьких по бокам
- Сетка промокодов (бонусов) с описанием, логотипом, кодом (с кнопкой «копировать») и ссылкой
- Раздел статей с категориями: Игровые, Новости интернета, Цифровые статьи, Крипто статьи
- Список последних статей и страницы статей с богатым форматированием
- Всплывающие окна 300×200 в левом нижнем углу: картинка, текст, промокод в рамке, кнопка

**Админ-панель (`/admin`):**
- Кнопка **«⟳ Обновить сайт»** — публикует изменения (до публикации правки видны только в админке)
- **Баннеры**: вкл/выкл, размер, картинка, ссылка с картинки, текст (вкл/выкл), кнопка (вкл/выкл) со ссылкой
- **Промокоды**: сервис, бонус, код, описание, картинка, ссылка
- **Статьи**: блочный редактор — абзацы (жирный/курсив/ссылка), заголовки H1–H3, кнопки, картинки
  (главная обложка + картинки между текстом; у каждой картинки подпись и кнопка с вкл/выкл)
- **Всплывающие окна**: картинка, текст, промокод в рамке, кнопка со ссылкой, вкл/выкл
- **Настройки**: название, слоган, контакты
- Загрузка картинок прямо из админки (или вставка ссылки)

## Запуск

```bash
npm install
npm start
```

- Сайт:    http://localhost:3000/
- Админка: http://localhost:3000/admin

**Пароль админки** по умолчанию: `admin123`
Поменять: переменная окружения `ADMIN_PASSWORD`, например:

```bash
ADMIN_PASSWORD="мой_пароль" PORT=8080 npm start
```

## Как это работает

1. В админке вы редактируете контент — изменения сохраняются как черновик.
2. Посетители видят последнюю **опубликованную** версию.
3. Нажмите **«Обновить сайт»** — и все изменения мгновенно появляются на сайте.

## Технологии

Node.js + Express, SQLite (`better-sqlite3`), EJS, Multer. Внешние сервисы не нужны —
база данных и загруженные файлы хранятся локально (`data/`, `uploads/`).
